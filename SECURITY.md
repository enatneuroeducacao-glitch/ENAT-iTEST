# Segurança e tratamento de dados

## Estado da aplicação

A versão atual é uma demonstração estática. Não utilize para provas reais, dados de alunos, credenciais ou informações institucionais confidenciais.

## Não publicar

- Senhas, tokens, chaves de API, certificados ou arquivos de ambiente.
- Bancos de dados, backups, arquivos legados com dados pessoais ou resultados reais.
- Capturas de tela com informações pessoais identificáveis.

## Reportar problemas

Abra uma issue sem incluir dados sensíveis, ou contate os mantenedores do repositório por um canal privado para vulnerabilidades que possam expor informações.

## Requisitos antes do uso real

- Autenticação e autorização no servidor.
- HTTPS e gerenciamento seguro de segredos.
- Validação de entrada no cliente e no servidor.
- Proteção contra abuso, tentativas indevidas e acesso a dados de outros usuários.
- Logs de auditoria com acesso restrito e sem segredos.
- Backups protegidos e restauração testada.
- Revisão de privacidade e retenção de dados.
- Testes de segurança e homologação antes da publicação funcional.
